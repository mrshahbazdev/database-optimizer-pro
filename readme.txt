Schedule and run database cleanups for revisions, drafts, transients and more with size analytics.

== Description ==

Database Optimizer Pro helps keep your WordPress database lean and fast.

Features:

* Clean post revisions, auto-drafts and trashed posts.
* Delete spam and trashed comments.
* Remove expired transients.
* Remove orphan post/comment/user meta.
* Database size and per-table analytics.
* Scheduled daily or weekly cleanups.

== Installation ==

1. Upload `database-optimizer-pro` to `wp-content/plugins/`.
2. Activate the plugin.
3. Go to **Tools > DB Optimizer Pro** and select cleanup options.
