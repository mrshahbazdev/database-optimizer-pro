# Database Optimizer Pro

A WordPress plugin to schedule and run database cleanups for revisions, drafts, transients and more with size analytics.

## Features

- Delete post revisions, auto-drafts and trashed posts.
- Delete spam and trashed comments.
- Remove expired transients.
- Remove orphan post/comment/user meta.
- Database size summary and per-table analytics.
- Daily or weekly scheduled cleanup.

## Installation

1. Download `database-optimizer-pro.zip` from [Releases](https://github.com/mrshahbazdev/database-optimizer-pro/releases).
2. Upload and extract to `wp-content/plugins/database-optimizer-pro/`.
3. Activate the plugin.
4. Go to **Tools > DB Optimizer Pro** and configure cleanup options.
